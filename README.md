# Máquina de Juegos en Ruby

## Descripción

Este proyecto consiste en una simulación de una máquina de juegos desarrollada en el lenguaje de programación Ruby. El programa permite al usuario ingresar una cantidad de dinero, verificar si es suficiente para jugar y calcular el cambio cuando corresponde. Además, muestra un arreglo con los juegos disponibles en la máquina.

## Objetivo

Desarrollar un programa en Ruby que permita aplicar conceptos básicos de programación como variables, arreglos, entrada de datos, estructuras condicionales y operaciones matemáticas.

## Lenguaje utilizado

- Ruby

## Funcionalidades desarrolladas

- Mostrar un menú con los juegos disponibles.
- Utilizar un arreglo para almacenar los nombres de los juegos.
- Solicitar al usuario la cantidad de dinero.
- Verificar si el dinero ingresado es suficiente para jugar.
- Calcular el cambio cuando el pago es mayor al precio de la partida.
- Mostrar cuánto dinero falta cuando el pago es insuficiente.
- Mostrar mensajes informativos durante la ejecución del programa.

## Instrucciones para ejecutar el programa

1. Tener instalado Ruby en el equipo o utilizar un compilador en línea compatible con Ruby, como MyCompiler.
2. Abrir el archivo `maquina_juegos.rb`.
3. Ejecutar el programa.
4. Introducir la cantidad de dinero cuando el sistema lo solicite.
5. Observar el resultado mostrado por el programa.
